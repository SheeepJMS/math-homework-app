诊断 CSV 格式说明

编码需为 UTF-8。从试卷详情页导入时，填 exam_id 或 competition_name+exam_title，以及 q_index（题号从 1 开始）。

下载模板 下载 CSV 模板
列说明
列名说明
competition_name竞赛名称（与 DiagCompetition.name 匹配）
exam_title试卷标题
exam_id试卷 ID（有则优先，可省略 competition_name/exam_title）
q_index题号，从 1 开始
stem_text题干文本，批量模式（无题目时）必填以创建题目；逐个模式不采用
correct_answer正确答案（A/B/C/D/E 或数值/文本）
solution_explain解析文本
answer_format可选，可留空：留空时系统自动推断——正确答案为单个 A–E 或题干含 (A)…(B)… 视为选择题，否则为填空。mcq/choice=选择；text/numeric/fill=填空；proof=证明简答。
choices_json可选：本题选项 JSON（对象如 {"A":"10","B":"12"}）。不填且题干为 Gauss 式 (A)…(B)… 时，导入会自动写入 choices_json。
kp_primary一级知识点
kp_secondary二级知识点（逗号或分号分隔）
needs_image有图/无图标记：1/yes/有/有图=该题需补充题干图或解析图，题目详情页会提示；0/无/空=无图可跳过
reserved_1 ~ reserved_3预留扩展
practice_count_default默认抽题数（默认 3）
practice_pool_size练习池大小（5–8 校验）
p1_stem … p8_stem错题练习题题干
p1_choices … p8_choices选项（JSON 或 "A)… B)…" 文本）
p1_answer … p8_answer答案
p1_explain … p8_explain解析
p1_source … p8_source可选：generated / manual / homework_bank

校验：每题至少 5 道练习题（stem+answer），practice_count_default ≤ 练习题数。
